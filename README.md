# REST Class — Mini REST API

Simple Node.js + Express REST application using EJS views.

**Prerequisites:**
- Node.js (16+ recommended)

**Install:**

```bash
npm install
```

**Run:**

```bash
node index.js
# or
npm start
```

The app serves views from the `views/` directory (index.ejs, show.ejs, new.ejs, edit.ejs) and static assets from `public/`.

If you cloned the repo, reinstall dependencies with `npm install`.

Notes:
- `node_modules/` is ignored (see .gitignore).
